\## Semana 6 — Autenticación, sesiones y seguridad

Aplicación Django conectada a MySQL mediante Aiven.

Incluye registro de usuarios, inicio y cierre de sesión,

y administración de servicios mediante CRUD.



Cada usuario puede consultar y administrar únicamente

sus propios servicios.



\## Prueba de aislamiento

Pendiente de completar: registrar dos usuarios diferentes,

crear un servicio con la primera cuenta, comprobar que no

aparece en la segunda y verificar que intentar editar un

servicio ajeno devuelve un error 404.
